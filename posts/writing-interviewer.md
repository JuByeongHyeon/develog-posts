# 인터뷰어라는 기능이 나왔어요!

> **요약**
>
> - 글쓰기 화면 오른쪽에 **「인터뷰 BETA」** 탭이 생겼어요.
> - 질문 몇 개에 한두 줄씩 답하면, 왼쪽 에디터에 글 초안이 쌓여요.
> - **어디서?** 새 글 쓰기 → 오른쪽 위 「출간 설정」 옆 **「인터뷰 BETA」** 탭

글을 쓰려고 에디터를 열었는데 커서만 깜빡이고 있을 때가 있잖아요.

오늘 뭔가 하긴 했는데, 막상 쓰려니 첫 문장이 안 나오는 날이요.

그럴 때 쓰라고 인터뷰어를 만들었어요. 누가 옆에서 몇 가지 물어봐 주면 생각보다 술술 나오더라고요.

## 어떻게 쓰나요

새 글 쓰기 화면에서 오른쪽 **「인터뷰 BETA」** 탭을 누르면 질문이 시작돼요.

![](https://data.develog.develrocket.com/upload/develog/wnqudgus1234/1791443123642-grv64f/02-_______-___-______.png)

&nbsp;

1. 요즘 새로 알게 됐거나 느낀 게 있어요?
2. 어떤 계기가 있었어요?
3. 한 줄로 정리하면요?
4. 오늘 얼마나 시간을 들였어요?

답을 보낼 때마다 왼쪽 에디터에 소제목과 함께 바로 들어가요. 마지막에는 제목 후보도 골라 볼 수 있어요.

## 이렇게 써 봤어요

처음 5km를 뛴 날, 이렇게 답해 봤어요.

- 요즘 새로 알게 됐거나 느낀 게 있어요? → **처음 5km 달리기**
- 어떤 계기가 있었어요? → **요즘 체력이 너무 떨어진 것 같아서**
- 한 줄로 정리하면요? → **결국 천천히라도 멈추지 않는 게 중요하다**

그러면 에디터에는 이렇게 쌓여요.

```
## 알게 되거나 느낀 것
해 본 건 처음 5km 달리기.

## 계기
요즘 체력이 너무 떨어진 것 같아서.

## 한 줄 정리
결국 천천히라도 멈추지 않는 게 중요하다.

> 들인 시간: 1시간 안쪽

```

![](https://data.develog.develrocket.com/upload/develog/wnqudgus1234/1791443123637-8lv37w/04-________-_______-______-_____-____.png)

여기서부터는 평소처럼 고쳐 쓰면 돼요. 더 하고 싶은 말은 더하고, 빼고 싶은 말은 빼고요.

## 알아 두면 좋은 것

- **칩을 눌러 보세요.** 「배운 건」, 「읽은 책은」 같은 칩을 누르면 첫마디를 채워 줘요. 뒷말만 이어 쓰면 돼요.
- **개발 얘기가 아니어도 돼요.** 읽은 책, 다녀온 곳, 요즘 드는 생각, 뭐든 괜찮아요.
- **오늘 쓸 게 없다면** 「딱히 없어요」를 눌러 보세요. 오늘 한 일 한 줄만 남겨도 기록이 돼요.
- **중간에 그만둬도 돼요.** 「그만하고 직접 쓸게요」를 누르면 지금까지 쓴 답은 그대로 두고 에디터로 돌아가요.
- **AI가 쓰는 건 아니에요.** 정해진 질문에 내가 한 답이 그대로 들어가요. 그래서 글은 온전히 내 글이에요.
- 글을 수정할 때는 인터뷰 탭이 나오지 않아요. 새 글을 쓸 때만 보여요.
